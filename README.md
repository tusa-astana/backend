# TUSA backend

API для [TUSA](https://tusa-astana.github.io/yessken.github.io/) — Telegram Mini App с каталогом событий Астаны, RSVP, интерес-группами и инструментами организатора.

Публичный каталог и участие бесплатны. TUSA не продаёт вход на офлайн-мероприятия; Stars используются только для цифровых сервисов внутри бота (когда checkout включён).

Подробности по запуску и эндпоинтам: [TusaMap.Api/README.md](TusaMap.Api/README.md).

## Support & Sponsorship
