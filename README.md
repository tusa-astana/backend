# TUSA backend

API для [TUSA](https://tusa-astana.github.io/yessken.github.io/) — Telegram Mini App с каталогом событий Астаны, RSVP, интерес-группами и инструментами организатора.

Публичный каталог и участие бесплатны. TUSA не продаёт вход на офлайн-мероприятия; Stars используются только для цифровых сервисов внутри бота (когда checkout включён).

Подробности по запуску и эндпоинтам: [TusaMap.Api/README.md](TusaMap.Api/README.md).

## Support & Sponsorship

Если API и экосистема TUSA вам полезны, поддержите проект:

- кнопка **Sponsor** на странице репозитория;
- в Telegram: `/donate` у [@tusa_astana_bot](https://t.me/tusa_astana_bot?start=donate).

Средства пойдут на:
- хостинг и сопровождение API;
- модерацию и развитие каталога;
- поддержку бота и безопасность (валидация Telegram `initData`, админ-доступ).

Спонсорство и донат не дают билетов на офлайн-события и не заменяют платные цифровые сервисы в Telegram.
